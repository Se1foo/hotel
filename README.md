# Hotel Booking System

A modern, responsive web application for managing hotel room reservations, guest check-ins, and real-time availability.

## Features
- **Online Reservation:** Seamless booking experience for guests.
- **Room Management:** Comprehensive dashboard for hotel staff to manage room status and pricing.
- **Availability Calendar:** Real-time updates on room availability.
- **Guest Profiles:** Secure storage of guest information and booking history.
